# Google Gemini Studio Application Prompt

Create a polished application prototype for **Taste of Paradise / T.O.P by HAI**. This is a HomelandAI-powered culinary innovation app for a rooftop test kitchen, live food streaming, recipe experimentation, sponsor-backed limited drops, community voting, gamified loyalty, and a growing recipe database.

## Navigation

Home / Live Sear Stage, Paradise Menu Lab, T.O.P Signature Menu, Recipe Vault, Taste Tester Waitlist, Loyalty / Rewards, Sponsor Drops, Profile, Admin / Establishment Settings, NCRD Gateway.

## Screens

Home should show The Sear Stage with close-up seared cake, technique stages, Heat Votes, Caramelization Meter, and collectible unlock. Paradise Menu Lab should show Tonight's Dish Builds, Ingredient Voting Matrix, Flavor Profile Ring, and HAI Cookbook pipeline. Signature Menu should show all major food collections. Recipe Vault should be searchable by breakfast, lunch, dinner, dessert, sponsors, collections, and status. Taste Tester Waitlist should support local signup and admin management.
