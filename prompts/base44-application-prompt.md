# Base44 Application Prompt

Build a mobile-first web app for **Taste of Paradise / T.O.P by HAI**. The app is a culinary innovation platform where users browse signature menu drops, vote on live recipes, join taste testing, collect HAI Cookbook cards, and engage with sponsor-backed food campaigns.

## Core Entities

Establishments, Users, Recipes, Collections, Menu Items, Live Episodes, Technique Stages, Ingredient Votes, Heat Votes, Flavor Profiles, Taste Tester Queue, Sponsors, Campaigns, Collectible Cards, Loyalty Events, Badges, Rewards, Media Assets, Notifications, NCRD Gateway Content.

## Screens

Home, Signature Menu, Recipe Vault, Paradise Menu Lab, Live Sear Stage, Taste Tester Waitlist, Loyalty Profile, Sponsor Drops, NCRD Gateway, Admin Dashboard.

## Functions

Add/edit/archive recipes, filter recipes, vote ingredients IN or OUT, send Heat Votes, manage technique stages, create collectible cards, manage taste tester waitlist, manage sponsors, track loyalty, and edit establishment settings.
