# Taste of Paradise — T.O.P by HAI

**Taste of Paradise (T.O.P by HAI)** is a HomelandAI culinary innovation platform built around a luxury tropical rooftop test kitchen, live streaming, community recipe voting, signature menu drops, sponsor-ready food collaborations, local taste tester participation, and collectible HAI Cookbook recipe cards.

Core tagline: **Cook. Vote. Collect.**

This repository summarizes the full conversation and converts it into a normal GitHub-ready product repository with documentation, prompts, backend architecture, seed data, and a lightweight Vite/React prototype.

## Core Product Pillars

1. **T.O.P Signature Menu** — rotating food collections: T.O.P Cups, Linzer Tarts, Burnt Ends, Seared Cakes, Paradise Bars, Paradise Shells, Island Tarts, Crepes, Madeleines, Pop-Tarts, and Twinkie Dippers.
2. **Paradise Menu Lab** — live community recipe-building with ingredient voting and a dynamic Flavor Profile Ring.
3. **The Sear Stage** — live cooking UI with technique stages, heat votes, caramelization meter, and collectible recipe unlocks.
4. **Recipe Vault** — searchable recipe database with breakfast, lunch, dinner, dessert, sponsor, source, status, and visibility filters.
5. **Taste Tester Waitlist** — local and VIP participant signup system for filmed reactions and fan-voted recipes.
6. **Sponsor-Ready Drops** — structured integrations for sauces, syrups, rum brands, farms, cacao, coffee, spices, and kitchen equipment.
7. **NCRD Gateway** — portal to North Coast RD Live for Dominican Republic North Coast events, tastings, venues, specials, rewards, polls, and alerts.

## Strategic Positioning

T.O.P by HAI should behave like a culinary content engine: food is the visual anchor, live voting is the engagement loop, taste testers provide local proof, collectible recipe cards create return behavior, sponsor drops create monetization, and the NCRD Gateway connects the concept to a broader Dominican Republic discovery ecosystem.

The prize distribution document was intentionally excluded from this build because this repo is focused on culinary programming, recipe systems, engagement, sponsorship, live-streaming, and product structure.
