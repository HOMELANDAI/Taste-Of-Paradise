# Implementation Roadmap

## Phase 1 — Foundation Website
Build Home, Signature Menu, Recipe Vault read-only view, Sponsor page, Taste Tester signup, NCRD Gateway, and social links.

## Phase 2 — Admin and Recipe Database
Build auth, admin dashboard, recipe CRUD, menu item CRUD, sponsor CRUD, media uploads, and establishment settings.

## Phase 3 — Live Engagement
Build live episode builder, Heat Voting, Ingredient Voting, Technique Stage controls, Flavor Profile Ring, and vote threshold logic.

## Phase 4 — Loyalty and Collectibles
Build user profiles, points, badges, leaderboards, collectible recipe cards, and VIP access rules.

## Phase 5 — Sponsor and NCRD Expansion
Build sponsor analytics, campaign management, QR unlocks, NCRD event feed, local alerts, and venue integrations.

## Phase 6 — Streaming Expansion
Integrate Twitch, Maestro.tv, YouTube replay embeds, vertical short clip library, and notifications.
