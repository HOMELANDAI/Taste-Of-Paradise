## Release trains
- MVP-A: public website + search/filter + CMS (P0–P3)
- MVP-B: local taster and consent/RSVP workflows (P4)
- Beta-C: live participation + rewards (P5–P6)
- V1: sponsors/NCRD, full QA, launch (P7–P9)

## Current status
Planning specifications and GitHub issue backlog are in place. Implementation, provider integrations, operating venue, paid sponsor relationships and production deployment are not yet verified as complete. A design mockup is not a functioning feature.

## Ticket workflow
Backlog → Ready → In Progress → Review → QA/Staging → Done. Every issue requires an acceptance test, review evidence, risk review and defined dependency.
