# Recipe Database

The Recipe Vault is a searchable and editable database for current and future T.O.P recipes.

## Filters

Breakfast, Lunch, Dinner, Desserts, Drinks, Snacks, Signature Series, Limited Edition, Sponsor Collab, Fan-Voted, VIP Only, Available Now, Coming Soon, Archived.

## Recipe Fields

recipeId, establishmentId, title, collection, category, mealType, cuisineInspiration, description, ingredients, instructions, prepTime, cookTime, difficulty, servings, allergens, dietaryTags, flavorTags, sourceType, originalCreator, originalSourceUrl, creditNotes, sponsorId, heroImage, videoUrl, streamClipUrl, reactionVideoUrl, status, visibility, heatScore, voteCount, flavorProfile, isSignatureMenu, isLimitedDrop, isSponsorReady, cookbookVolume, collectibleCardId, dateAdded, lastTestedDate.

## Admin Functions

Add recipe, edit recipe, archive recipe, feature recipe, send recipe to vote, send recipe to test kitchen, approve for cookbook, attach sponsor, add reaction video, and generate collectible card.
