# NCRD Gateway

The NCRD Gateway connects T.O.P by HAI to **North Coast RD Live**, the broader HomelandAI ecosystem for Dominican Republic North Coast discovery and local engagement.

## Gateway Modules

Local food events, tastings, venue openings, theme nights, rooftop experiences, restaurant specials, VR/XR room programming, gaming schedules, rewards, polling, alerts, and app-based discovery.

## Placement

Add NCRD Gateway to the main navigation, hero CTAs, footer, sponsor page, events page, and user dashboard.

## CTA Examples

Enter North Coast RD Live, Discover Local Events, View Tastings, Partner With NCRD, Return to T.O.P.
