# Live UI Systems

## The Sear Stage

The Sear Stage is the flagship live cooking interface. It shows a close-up food cam, an amber-copper pan, a cake slice searing, a Technique Stage panel, a Caramelization Meter, heat votes, live chat, and a collectible recipe card unlock.

Technique stages: PREP, HEAT, SEAR, REST, PLATE.

## Caramelization Meter

The meter fills from ember-orange to bright gold as the community sends Heat Votes. It converts viewer input into visible culinary progress.

## Paradise Menu Lab

Paradise Menu Lab is the live community recipe-building interface. It includes Tonight's Dish Builds, Ingredient Voting Matrix, live chef feed, Flavor Profile Ring, vote threshold, and HAI Cookbook pipeline.

Flavor colors: Sweet = amber, Spice = ember, Fresh = sage, Rich = gold, Tart = ruby, Smoky = charcoal, Creamy = parchment.

Pipeline: Community Votes, Chef Review, Test Kitchen, Taste Tester Reaction, Cookbook Vol. II, Signature Menu Candidate.
