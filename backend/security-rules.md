# Security and Permission Notes

Visitors can read public recipes, menu items, sponsor campaigns, limited drops, and NCRD content. Authenticated users can vote, save recipes, apply for taste testing, earn points, and collect unlocked cards. Admins can manage recipes, sponsors, establishment settings, taste testers, and live stages.

Protect votes by blocking duplicates per user per ingredient per session, rate-limiting Heat Votes, storing audit records for suspicious spikes, and closing sessions after end time. Store filming consent and dietary restrictions for taste tester safety.
